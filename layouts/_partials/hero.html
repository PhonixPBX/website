The appliance PBX,
reborn.

PhonixPBX is the open-source successor of AskoziaPBX: a complete telephone system built on Asterisk 22 and Alpine Linux, managed from a clean web interface. Flash it on a Raspberry Pi, boot it on a PC, or run it as a container — it is up and taking calls in minutes.
